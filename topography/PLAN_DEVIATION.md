# Plan deviation 1

Recorded before any channel-level relative-alpha or rank outcome was calculated.

The plan stated that a missing or reordered channel stops the analysis. During extraction, a survey of all EDF headers found one participant (sub-075) whose pre- and post-battery files list the same 64 EEG labels with Fp1 and Fp2 in swapped positions. All other files (530 pre-battery, 523 post-battery) match the reference order.

Channels are selected by label in every file, so the order of channels in a file does not change which signal is analysed.

Change: files containing the same 64 EEG labels in a different order are accepted, and channels are selected by label. A missing, duplicated or extra label still stops the analysis. Nothing else in the plan changes.
