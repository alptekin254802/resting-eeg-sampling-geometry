ADDITIONAL MEASUREMENT ANALYSES, VERSION 2026-11-07

Temporal Sampling Geometry and Participant-Level Reproducibility in Fixed-Duration Resting EEG

Part of software version 2026-11-07.
This version supplies the exploratory within-participant absolute-difference,
pre/post recording, spectral-normalization, and fixed-sample re-pairing analyses.
They were planned after the original results were known. They are separate from
the original preregistration.

The source datasets are OpenNeuro ds005385 v1.0.3 and ds004148 v1.0.0.
The original input and result arrays are unchanged.
Raw EEG is obtained separately from the versioned data providers.

ENVIRONMENT AND VERIFICATION
Run commands from this directory, using Python 3.14.3 and requirements.txt.
python -m pip install -r requirements.txt
python -B src/verify_manifest.py
python -B -m unittest discover -s tests -v
python -B src/verify_results.py

The numerical verifier checks saved-array points/intervals, participant alignment,
pairing preservation, schedules, all agreement-bootstrap means, and three direct
ordinary-bootstrap resamples per rank-analysis block. It does not reprocess raw
EEG or rerun every rank-bootstrap resample. It prints its report to standard
output and changes no files. To save the report, add --output <path> with a
path outside the distributed files, for example outputs/verification.json.
The supplied VERIFICATION.json is a fixed copy of this report.

REGENERATE DISPLAYS
python -B src/build_displays.py --output outputs/displays
This creates Figures 1–4, S1, S4–S5 and Tables S5–S9. The reporting table is supplied
as templates/table_s9_reporting.tex. The original temporal-order/simulation
Figures S2–S3 are generated by the main study software.

RECOMPUTE FROM DERIVED INPUTS
Work in a copy to preserve the supplied reference files. These commands overwrite
the copy's corresponding local result files and can take substantial time:
python -B src/run_cached.py agreement
python -B src/run_cached.py normalization
python -B src/run_cached.py pairing_prepare
python -B src/run_cached.py pairing
python -B src/run_post.py infer

RECONSTRUCT POST METADATA
Use a metadata checkout of ds005385 v1.0.3 at commit
6a558cd5852503e66df9ac7fdac2f3a7f4ed5f12:
https://github.com/OpenNeuroDatasets/ds005385/tree/6a558cd5852503e66df9ac7fdac2f3a7f4ed5f12
Preserve its small annex pointers (regular text files or Git annex symlinks),
EEG JSON sidecars, channel TSV and event TSV files. Do not replace the pointer
files in this metadata checkout with signal payloads.
python -B src/prepare_post_metadata.py --snapshot-root "raw_metadata/ds005385"
An optional --output argument writes reconstructed metadata into a new empty
directory. The default compares all 531 rows and their nine fields with the
supplied metadata; 527 recordings pass the metadata screen. This step reads no EEG.

OPTIONAL POST RECONSTRUCTION FROM RAW EEG
Source: https://openneuro.org/datasets/ds005385/versions/1.0.3
Place each of the 527 eligible EDF payloads at raw_post/<path>, where <path>,
expected byte count, and SHA-256 are recorded in metadata/post_metadata.json.
python -B src/run_post.py prepare
python -B src/run_post.py infer
The commands stop with an error if a file is missing or its checksum differs. For
each participant, preparation writes a record of the input checksums,
configuration, code modules and prepared outputs; records that do not match the
current inputs are rejected. Use a fresh working copy after changing code or
configuration. These records are not distributed.

INTERPRETATION AND PROVENANCE
The bootstrap unit is the participant, carrying all compared conditions together.
Intervals are exploratory 95% percentile intervals, not adjusted for multiple
comparisons. Pre/post recordings bracket cognitive activity and elapsed time.
Re-pairing preserves individual sample measurements but does not equate distance
ranges between geometries. configuration.json keeps the original wording of the
event screen and records the type-only screen that was actually run.
metadata/remote_version_tag.json records the data-release version used.
manifest.json lists the file checksums for this directory. LICENSE.txt explains the
MIT software, CC BY 4.0 original content, and source-data attribution scopes.
